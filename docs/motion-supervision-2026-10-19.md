It did not establish an artistically integrated entry/gesture/transition. The code's sandbox, safe-area and encoded-frame checks did not assess fulfillment of the creative note. Shimi's golden rule is that Claude supervises production decisions and all feedback. Application code executes, measures and persists, retaining spending authorization and human approvals. Do not promise that a prompt alone makes every pipeline compliant.

## New Motion path

1. A feedback price request sends exact script, scenes, targets, previous finishing notes and current note to the durable Claude agent. It returns visual/finishing/mixed interpretation. Mixed notes retain their finishing part; no keyword router decides that meaning. The original note stays attached to the quote.
2. A normal-cost estimate uses configured-model provider rates, source/context size, selected code scope and visual-review images. This is an estimate, not metered usage. Feedback pricing is estimated supplier cost ×12, rounded up to a whole dollar. It includes feedback interpretation, code revision and visual review, excludes initial generation and bug retries. Initial price remains $10; existing accepted totals remain intact; the existing $20 cumulative ceiling is retained. No generation is launched by quoting. Approval binds exact ID, revision, source hash, targets, feedback, amount and expiry.
3. A new writer operation pins contract 4. Revisions receive before images and must provide an intention, compositional integration, movement, preservation requirements and a visible proof goal for every selected scene, along with a source-bound patch.
4. The trusted runtime compiles the source and measures timing, readability, logo presence and technical correctness. It samples four labelled frames per scene: entry, settled entry, midpoint and outgoing boundary. These checks do not claim creative acceptance.
5. A separate durable Claude review sees before/after contact sheets and four frames from the validated reference. It must assess every selected scene, the exact source hash, request fulfillment, integration, motion evidence, readability and brand consistency. A rejected verdict is saved, then passed to the existing bounded repair flow with the original note and saved candidate. A compilation pass cannot override it.
6. Only a matching Claude approval receipt can publish new-contract code. The normal full-film render still performs encoded-frame comparisons and preserves human storyboard, visual-film and finishing approvals. Source/review provenance is checked again before final release.

The visual-review allowance is carved out of the existing writer allowance, not added on top. Snapshot bytes are frozen before reviewer inference. The same failed or successful review is reused after restart even if later browser rasterization varies slightly. Old contract-2/3 paid inputs and receipts remain unchanged. No existing production is automatically migrated or retried.

## Release supervision across categories

Clay, Motion and Attack now call a shared durable Claude release review before settlement and download publication. It receives the exact final-file SHA256, human approval action, current feedback/settings, measured results and available sampled images. A negative verdict returns specific unresolved corrections and leaves the final version unapproved and uncharged at settlement. A repeated request reuses the saved verdict; changed feedback facts require a new decision. Changed file bytes fail before inference. Model selection is restricted to Claude. This is a release review, not an additional client approval stage.

## Boundaries, not claimed as done

- Contact sheets are sampled visual evidence. They cannot prove smooth complete playback, audible narration or artistic satisfaction. Human complete-film and finishing review remain necessary.
- The live opening-logo art is still rejected by Shimi; this engineering change does not redraw or approve it.
- Clay's semantic feedback director already uses Claude with visual references; Attack uses Claude direction/finishing and sampled media inspection. Their final releases now also pass through Claude. However, legacy Clay/Attack technical recovery routing still uses explicit execution-state rules; arbitrary repair of application code is not delegated to the production model. Do not describe all three categories as fully equivalent to a direct Claude conversation.
- Existing safe-spending/reconciliation limits still apply if a provider is unavailable or repeatedly returns invalid results. An indefinite paid retry is not a quality strategy.
