# Motion MD02 : le diagnostic incomplet masquait le brouillon

Constat client du 19 octobre 2026, production `bdb75cbe-e391-4e1a-ae1d-bb8e7d2c2f75`.

## Ce qui a réellement échoué

Les reçus enregistrés montrent un brouillon Python reçu, puis quatre réponses du writer au total. Le brouillon recopie treize fonctions du moteur à l'identique. L'assembleur rejetait tout `def` dans la composition avec un message générique. Après deux rejets identiques, le runtime remplaçait ce diagnostic par un arrêt générique. Le superviseur recevait `hasFilm:false` parce que l'opération n'était pas terminée, alors que son résultat contenait le code rejeté. Claude a donc conclu à tort qu'aucun code n'était disponible pour réparation. Son raisonnement technique s'affichait directement dans l'interface.

Les parcours antérieurs avec réponses simulées n'avaient pas reproduit cette réponse réelle. Leur réussite ne démontrait pas que le writer réel pouvait terminer ce nouveau film.

## Corrections exécutées

- L'arrêt sur rejets identiques conserve la dernière réponse et le diagnostic précis du validateur.
- Le superviseur reçoit le code rejeté, distingue sa présence de sa validation et dispose de l'outil de réparation. Le code ne décide pas à sa place de la correction créative.
- L'assembleur écarte uniquement les copies AST-identiques des fonctions et initialisations du préambule, avant la première scène. Les définitions modifiées restent interdites et indiquent nom et ligne. Les contrôles visuels, de son et de narration ne sont pas affaiblis.
- Le repérage des scènes accepte les deux syntaxes Python de guillemets, avec le même contrôle du périmètre des révisions.
- `reason` reste interne ; `clientMessage` est une phrase courte destinée au client. Les anciens diagnostics ne sont plus affichés bruts.
- Un ancien dossier bloqué par ce diagnostic incomplet propose une reprise explicite. Elle récupère le rejet original de cette vidéo/révision avant une nouvelle analyse. Historique, plafonds, audio et reçus restent conservés ; aucune reprise n'est déclenchée par un simple affichage de la page.

## État réel du test

La relecture locale du brouillon sauvegardé passe désormais l'assemblage du préambule. Elle révèle aussi une composition de neuf scènes pour onze phrases attendues. Cette correction créative reste à faire par Claude : le film n'est pas déclaré terminé, aucune validation n'a été contournée, aucune génération payante n'a été lancée pendant cette intervention.
